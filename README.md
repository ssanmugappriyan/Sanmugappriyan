## Featured Projects

### 1. Synchronous FIFO Design – Verilog HDL
**Status:** In Progress

A synchronous First-In First-Out (FIFO) memory design implemented using Verilog HDL.

Key concepts:
- Read and write pointer management
- Memory array implementation
- Full and empty flag generation
- Synchronous reset and clocking
- Self-checking testbench and simulation

**Tools:** Verilog HDL, Icarus Verilog, GTKWave

### 2. Traffic Light Controller – VHDL
**Status:** In Progress

A Moore finite state machine (FSM) designed in VHDL to control traffic light transitions.

Key concepts:
- Moore FSM architecture
- State transition logic
- Output decoding
- VHDL testbench development
- Simulation and verification

**Tools:** VHDL, ModelSim

### 3. Smart Kinesio Tape – Knee Rehabilitation Monitoring

A wearable knee rehabilitation monitoring prototype integrating motion sensors and embedded hardware for real-time movement feedback.

Key features:
- MPU6050 motion sensor integration
- ESP32-C3 microcontroller
- LED-based feedback system
- Wireless monitoring using Wi-Fi
- Web-based visualization dashboard

**Technologies:** ESP32-C3, MPU6050, C++, HTML, CSS, JavaScript
